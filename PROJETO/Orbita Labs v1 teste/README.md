# Orbita Labs v1 teste

Antes se chamava Orbita Labs v1 --- teste. É a cópia da v1 que a turma criou no fim da aula 1.

## O que faz

O mesmo que a Orbita Labs v1. Os nós e as expressões são iguais, muda só a posição no canvas. A explicação de cada nó está no README da pasta Orbita Labs v1.

Quando um fluxo já funciona, é mais seguro testar ideias numa cópia. Se algo der errado, o original continua do jeito que estava.

## Como testar

Igual à v1. Importe, clique em Execute workflow, copie a Test URL do Disparo de Gatilho e mande um POST com o campo nome no corpo.

Também dá para mandar a chamada pelo [Postman](https://www.postman.com/downloads/), pelo [Insomnia](https://insomnia.rest/download) ou pelo [Thunder Client](https://marketplace.visualstudio.com/items?itemName=rangav.vscode-thunder-client), uma extensão do VS Code. Use a Test URL depois de clicar em Execute workflow, ou a Production URL depois de publicar o fluxo.

## Erros comuns

As duas versões usam o caminho senai-orbita-v1. Por isso só uma pode ficar publicada. Para publicar a cópia, despublique a original antes ou troque o caminho da cópia para senai-orbita-v1-teste.
