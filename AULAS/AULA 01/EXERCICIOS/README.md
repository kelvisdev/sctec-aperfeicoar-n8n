# Exercícios da aula 1

Três exercícios curtos para treinar o que vimos na aula 1. Cada pasta tem o enunciado no README, o fluxo de partida (partida.json) e a resposta (gabarito.json).

Importe o partida.json, tente resolver e só depois abra o gabarito. Se o seu ficou diferente e a saída bate, está certo também.

| Pasta | O que você treina |
|---|---|
| 1 Etiqueta do participante | dados fixados, Edit Fields e toUpperCase |
| 2 Mensagem pela URL | webhook GET, dados da URL e Respond to Webhook |
| 3 Conserte o webhook | achar defeitos num fluxo pela mensagem de erro e pela saída de cada nó |

Use só dados inventados nos testes.
